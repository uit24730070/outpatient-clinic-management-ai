# API

Chứa tài liệu đặc tả API của hệ thống.

Nội dung dự kiến:

- Quy ước thiết kế **RESTful API** (đặt tên resource, HTTP method, status code)
- Đặc tả endpoint: request/response, tham số, ví dụ
- Quy ước xử lý lỗi và định dạng phản hồi lỗi chuẩn
- Chiến lược versioning API
- Liên kết tới đặc tả OpenAPI/Swagger và bộ sưu tập [Postman](../../postman)
