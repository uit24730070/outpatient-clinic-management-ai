# Kiến trúc (architecture)

Chứa tài liệu mô tả kiến trúc tổng thể của hệ thống.

Nội dung dự kiến:

- Tổng quan kiến trúc hệ thống (system overview)
- Áp dụng **Clean Architecture** ở backend: vai trò từng lớp (Domain, Application, Infrastructure, WebApi, Shared) và quy tắc phụ thuộc
- Kiến trúc frontend (React + TypeScript): tổ chức feature, state, routing
- Luồng dữ liệu và tích hợp giữa các thành phần (Frontend ↔ WebApi ↔ Database ↔ LLM API)
- Nguyên tắc thiết kế, ràng buộc kỹ thuật, non-functional requirements
