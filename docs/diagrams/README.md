# Biểu đồ (diagrams)

Chứa các biểu đồ mô hình hóa hệ thống.

Nội dung dự kiến:

- **Use Case Diagram** — sơ đồ ca sử dụng
- **Sequence Diagram** — sơ đồ tuần tự cho các luồng chính
- **Component Diagram** — sơ đồ thành phần
- **Deployment Diagram** — sơ đồ triển khai
- **Activity / Flow Diagram** — luồng nghiệp vụ

> Khuyến nghị dùng định dạng có thể version-control được (ví dụ: PlantUML, Mermaid, `.drawio`). File ảnh xuất ra đặt tại [`../assets`](../assets).
