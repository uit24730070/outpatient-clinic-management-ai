# Tài nguyên tài liệu (assets)

Chứa các tài nguyên tĩnh được nhúng vào tài liệu: hình ảnh, ảnh chụp màn hình, ảnh xuất từ biểu đồ, logo...

Khuyến nghị:

- Đặt tên file có ý nghĩa, không dấu, dùng gạch nối: `so-do-kien-truc.png`
- Ưu tiên định dạng nhẹ (`.png`, `.svg`) cho ảnh minh họa
- Tham chiếu tương đối từ tài liệu Markdown, ví dụ: `![Kiến trúc](../assets/so-do-kien-truc.png)`
