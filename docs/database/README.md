# Cơ sở dữ liệu (database)

Chứa toàn bộ tài liệu thiết kế cơ sở dữ liệu PostgreSQL.

Nội dung dự kiến:

- **ERD** — sơ đồ quan hệ thực thể (Entity Relationship Diagram)
- **Thiết kế cơ sở dữ liệu** — mô hình bảng, khóa chính/ngoại, ràng buộc, index
- **Database Dictionary** — từ điển dữ liệu: mô tả từng bảng, từng cột, kiểu dữ liệu, ý nghĩa
- **Migration Guide** — hướng dẫn tạo và áp dụng migration

> Script SQL và migration thực thi được đặt tại thư mục [`/database`](../../database) ở gốc dự án.
